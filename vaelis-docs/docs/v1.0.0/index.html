Vaelis documentation

Everything you need to build 2D games with Vaelis 1.0.0, verified against the engine source.

View as Markdownllms.txt
What is Vaelis?A browser-based 2D game engine with a Unity-style visual editor, an entity–component runtime built on PixiJS (rendering) and Rapier2D (physics), and a JavaScript scripting API. The editor, runtime and exporter ship as a static site — no build server is needed to make or play games.

Dynamic, Kinematic and Static bodies have different script…Collider2DPhysics collision shape and contact filtering. A Collider2D is also required for accurate pointer/touch hit tests.Joint2DConnect physics bodies with Fixed, Revolute, Prismatic, Rope or Spring constraints.CharacterControllerHigh-level movement modes: Character Controller, Platformer, Top-Down, Car, Follow, Patrol and Free.SpriteAnimationSprite-sheet/clip animation state on a SpriteRenderer.CameraOrthographic 2D camera with reference resolutions, responsive scaling, follow, shake and optional pseudo-3D sprite…AudioSourcePlay a local audio asset, optionally with distance-based 3D attenuation.AudioListenerDefines the hearing area for 3D audio and drives audio enter/leave callbacks.Light2D light source supporting Directional, Point, Spot, Area, GodRays and Freeform light shapes.ShadowCasterMarks an entity as a shadow occluder for the lighting system.LightingSettingsScene-wide lighting quality and mood controls. Attach to one entity; the lighting system reads it scene-wide.NavAgent2DPer-agent navigation settings and current path state for NavWorld2D pathfinding.NavWorld2DShared navigation world for baked or dynamic 2D pathfinding, with 16 navigation areas.TilesetDefines a reusable 16-role autotile set.
